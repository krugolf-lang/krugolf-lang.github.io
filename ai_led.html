Topic ต้องตรงกับในโค้ด ESP และตั้งให้ไม่ซ้ำใคร (broker เป็นสาธารณะ)
วิธีใช้งานบนมือถือ + เรื่องที่ต้องรู้

⚠️ ไฟ 220V อันตรายถึงชีวิต — ต่อผ่านรีเลย์ที่มี optocoupler ใส่กล่องปิดมิดชิด และให้ครูดูแลเสมอ ทดสอบด้วย LED ก่อน

  1. อัปโหลดโค้ด ESP เวอร์ชัน MQTT แล้วเช็ค Serial Monitor ว่าขึ้น "เชื่อม MQTT สำเร็จ"
  2. ตั้ง Topic ในหน้านี้ให้ ตรงกับ topic_cmd ในโค้ด ESP เป๊ะ ๆ
  3. เอาไฟล์นี้ขึ้น GitHub Pages (เป็น https) แล้วเปิดลิงก์บนมือถือ
  4. เปิดกล้อง → เปิดสวิตช์ "ส่งคำสั่งไปไฟจริง" → แบมือ/กำมือ ไฟจริงจะทำงาน

ทำไมถึงคุมข้ามเครือข่ายได้: ทั้งมือถือและ ESP ต่างวิ่งออกไปหา broker.hivemq.com เลยไม่ต้องอยู่ WiFi เดียวกัน และไม่ติด mixed-content เหมือนการยิง IP ตรง ๆ

หมายเหตุ: broker สาธารณะนี้เหมาะสำหรับเรียน/ทดสอบ ใครรู้ Topic ก็ส่งได้ ถ้าใช้จริงจังควรตั้ง Topic ที่เดายาก หรือใช้ broker ส่วนตัว
